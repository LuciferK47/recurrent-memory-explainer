1. Executive Summary & Locked Claim

Autoregressive Transformers enable in-context learning via an explicit key–value (KV) cache scaling linearly with sequence length ($O(n)$ memory footprint per sequence), creating massive memory bandwidth and VRAM constraints. Fixed-size recurrent memory replaces unbounded buffers with a state matrix $M \in \mathbb{R}^{d \times d}$, achieving strictly $O(1)$ memory complexity during inference.

Locked Claim: “A fixed-size recurrent memory can absorb key–value associations from demonstrations and recall them accurately — until the number of associations exceeds the memory's rank, at which point recall degrades through interference in a predictable, measurable way.”

2. Algebraic Substrate: Hebbian Write & Readout

Associative memory updates via two primitive tensor operations:

1. Outer-Product Write: M ← M + v · kT  (Hebbian rank-1 write)
2. Linear Readout:       v̂ = M · q = ∑i=1..N vi (kiT q)

For query $q = k_j$, readout decomposes into signal and cross-talk:
v̂ = vj (kjT kj) + ∑i ≠ j vi (kiT kj) = vj + ∑i ≠ j vi (kiT kj). If keys are mutually orthogonal (kiT kj = 0), retrieval is exact.

3. The Capacity Cliff & Interference

In $\mathbb{R}^d$, at most $d$ orthogonal vectors exist. Once stored pairs $N > d$, cross-talk corrupts retrieval:

  • Sub-capacity ($N \le d$): Cosine similarity $\approx 1.0$; near-perfect recall.
  • Critical Threshold ($N \approx d$): Interference noise equals primary signal.
  • Interference Regime ($N \gg d$): Accuracy plunges toward $1/\sqrt{d}$ noise floor.

Interference is not a numerical error; it is the fundamental information-theoretic tax of bounded state compression.

5. Role of BDH & BDH-CQ

  • BDH (arXiv:2509.26507): Biologically-inspired, scale-free graph of neuron particles where working memory emerges directly from Hebbian synaptic plasticity. Low-rank GPU formulation runs with ~5% activation sparsity and monosemantic wiring.
  • BDH-CQ (arXiv:2608.09888): Absorbs demonstration pairs (e.g. ARC-AGI grids) into recurrent state without backpropagation or chain-of-thought tokens, querying state to output solutions.

6. Evidence Discipline & Honest Limitations

  • Self-Reported Benchmark 29.5% pass@2 on ARC-AGI-1 ($0.0007/task) is audited by partner-institution co-authors, not an arm's-length external lab. Scaling laws across multi-scale models remain unproven.
  • Disclosed Failure: BDH-CQ failed completely (0/72) on color-swap composition tasks, exposing vulnerability of pure outer-product states to relational logic.
  • Didactic Scope: Explainer runs live mathematical Hebbian updates in JS/TS to illuminate principles, without misrepresenting itself as the proprietary engine.
