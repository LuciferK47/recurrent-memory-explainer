How Fixed-Size Memory
Learns — and Forgets

Claim: A fixed-size recurrent memory can absorb key–value associations from demonstrations and recall them accurately — until the number of associations exceeds the memory's rank, at which point recall degrades through interference in a predictable, measurable way.

01 The Problem

Transformers Remember Everything. That's Expensive.

Standard Transformers store every past token in a key–value cache that grows linearly with context length. More context = more memory = more cost.

KV-Cache Growth O(n) Scaling

Each new token adds a new key and value vector. At sequence length n, memory usage is O(n). For long conversations, this becomes the dominant cost.

The Alternative: Fixed-Size State O(1) Memory

What if instead of growing the cache, we compress everything into a fixed-size matrix? Memory stays constant — O(1) — regardless of sequence length. But there's a cost…

The Fundamental Tradeoff

Property KV-Cache (Transformer) Fixed-Size Recurrent State
Memory per step Grows: O(n) Constant: O(1)
Recall fidelity Perfect — everything stored Degrades under load
Inference cost Grows with context Constant
Failure mode OOM / quadratic slowdown Interference — memories corrupt each other

This is the core tradeoff this explainer teaches. BDH (arXiv:2509.26507) and BDH-CQ (arXiv:2608.09888) implement the fixed-size approach — Section 3 explains how.

03 BDH Connection

How BDH and BDH-CQ Use This Mechanism

The outer-product write you just used is BDH's core memory mechanism. Here's how it works in the actual architecture.

🧠 Learning Objective

After this section, you should be able to explain: BDH stores attention as synaptic memory that updates via Hebbian writes as the model reads. BDH-CQ extends this to absorb demonstration examples into recurrent state — enabling in-context learning without gradient updates.

BDH: Attention as Synaptic Memory

In a standard Transformer, attention is a lookup: query against stored keys to retrieve values. In BDH (arXiv:2509.26507), this lookup is reformulated as synaptic memory — connections between neuron-like units that strengthen when related concepts co-occur.

$S(t) = S(t−1) + \eta \cdot v(t) \cdot k(t)^T$   (Hebbian synaptic update)

This is exactly the outer-product write M ← M + v · kᵀ you used in Section 2. S is the synapse matrix (fixed-size), v and k are the value and key at time t, and η is a learning rate.

Key distinction: BDH is not an SSM in the Mamba sense. BDH models neuron-synapse interactions on a scale-free graph; BDH-GPU is a separate GPU-friendly reformulation using ReLU/low-rank transformations with linear attention (arXiv:2509.26507, Section 4).

BDH-CQ: Learning from Demonstrations

BDH-CQ (arXiv:2608.09888) extends BDH to learn from a few demonstration examples at inference time. Each demo pair is written into recurrent state. No gradient update. No chain-of-thought tokens. Click through to see how:

🪞 Check Your Understanding

In your own words: why does recall degrade after the number of stored associations exceeds the memory dimension d? What would happen if all keys were perfectly orthogonal?

Hint: Think about what happens to $M \cdot q$ when $q$ is similar to multiple stored keys. If keys are orthogonal, cross-terms vanish — but in $d$ dimensions, you can only have $d$ orthogonal vectors.

Known Limitations (from the paper itself)

🔬 The Open Question

Can fixed-size recurrent memory match KV-cache recall fidelity on long-context tasks without resorting to hybrid approaches? The interference cliff you saw in Section 4 is the fundamental barrier. Gating, normalization, and selective writing can push it back — but they don't eliminate it.

This remains an active area of research. See: Gated DeltaNet (arXiv:2412.06464), Variational Linear Attention (arXiv:2605.11196).
