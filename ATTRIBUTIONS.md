## Reference image

`react-app/public/bg-plate.webp` is a heavily blurred, darkened, and
downscaled derivative of one AI-generated concept-art reference image used
during design exploration for the background (not a photograph, not a
third-party asset with its own license — it was generated as a design
reference for this project). The processing (Gaussian blur, colorize,
downscale — see the generation command documented in
`react-app/src/components/ScaleFreeBackground.tsx`) is deliberate: it
reduces the source to an atmospheric colour wash only, since the source was
never intended to be legible or attributable as a standalone image.
